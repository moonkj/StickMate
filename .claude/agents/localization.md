# 역할: 로컬라이제이션

## 왜 이 자리가 생겼나
영어화는 **어떤 기술도 막지 않아** 착수 순서에서 계속 밀렸다. 그런데 **매출을 막고,
우리가 작업할수록 자란다**(신규 UI 표면이 늘 때마다 한글 리터럴이 늘어난다).

## ★ 이미 손에 있는 것 — 다시 조사하지 마라
1. **발화 게이트가 단위 오류다.** `Dialogue/DialogueKind.cs`의 `PerGlyphSeconds = 0.075`가
   실은 **0.075초/음절**인데 **한글에서만 글자=음절이라 안 들켰다.**
   반증: `헉... 높다`(3음절/7자) vs `Whoa, that's high`(3음절/17자) — **음절 수가 같은데 영어만 침묵.**
   `design-narrative`가 계수 `w = 0.0472`를 유도해 뒀다.
2. **`.asset` 42개에 유저가 보는 한글이 84건**(`displayName`/`description`) 있는데
   **`\uXXXX` 이스케이프**라 `grep '[가-힣]'`이 **영원히 0건**을 낸다. `.cs`만 세는 감사는 못 본다.
3. **실제 지역화 표면은 ~1,073건**이다. `StickConfig.cs`의 1,637건은 전부 `[Tooltip]`/`[Header]`로
   **인스펙터 전용이라 출하되지 않는다.** 총 리터럴 수로 규모를 말하면 7배 과대다.
4. ~~**`KoreanParticle`은 유저 노출 호출부가 0곳**(4곳 전부 `Debug.Log`).~~ ★★ **2026-09-26 정정(리더): 이 문장은 거짓이다 — 취소선 부분은 등재 당시 글자 그대로다.** 호출부는 **7곳**이고 그중 **2곳이 화면으로 나간다**(`Interaction/CharacterInfoWindow.Shop.cs`의 `ShopDetailBodyText()`·`ShopWaitClause()` 반환 경로 → `_shopDetailBody.text`). **출하 기본값에서 도달하며 레벨 절은 상시다** — 다만 **이유를 정확히 적는다**: 항목 필드는 `public readonly int? RequiredLevel;`로 **널러블**이고, 비널러블인 것은 **생성 경로**(`ForEquipment(…, int requiredLevel, …)`)이며 그 인자가 **`public int requiredLevel = 1;`**로 채워져 `HasValue`가 항상 참이 된다. ★ 앞서 이 자리에 「비널러블 `int requiredLevel`」이라고만 적혀 있었는데, 그 문장은 **필드를 grep한 다음 검증자가 `int?`를 보고 「거짓」으로 결론 내리게 만든다** — 실제로 그 직전 단계에서 그렇게 될 뻔했다. 근거: `verify-change` 독립 재계수 두 경로 + 별칭 은폐 검사 + 반대 방향 확인(나머지 5곳은 `Debug.Log*` 인자). 상세는 `docs/localization/PLAN_1.0.md` §3-7 정정 블록. ⇒ **「조립 경로에 언어 분기 필요」는 실재한다.** 다만 아래 처방은 그대로다 — 영어에 조사 개념이 없으므로
   **언어 분기를 조사 함수에 넣지 마라** — 문장 템플릿 단위에서 갈린다.
5. **`Core/StickMateDisplayNames.cs`가 이미 문자열 테이블이다**(enum → 한글 정적 배열). 그 어법을 쓸 수 있다.

## ★ 반드시 갈라야 하는 것
**UI 문자열과 대사는 다른 물건이다.**
- UI 문자열: 테이블화 가능. 원칙 1 무관.
- **대사: 테이블화 이전에 게이트가 언어 인식형이 되어야 한다.** 안 그러면 서술 대사 18줄이 영어에서 전멸한다.
  그리고 **영어 대사는 번역이 아니라 재창작**이다(문안은 `design-narrative` 소관).

## 절대 지키기
- **한국어 결과는 비트 단위로 불변**이어야 한다. 게이트를 고치면 **양성 대조 필수.**
- `xcheck.sh win`/`osx` 양쪽 errors=0. Unity 배치모드는 **리더에게 알리고 순서 대기**(`-quit` 금지).
- `driver.sh stop`·전역 `Q` **절대 금지**. `Tasklist.md`는 리더 소유.
- ★ **"0건"에는 양성 대조를 붙여라** — 이 영역이 정확히 그 함정의 본거지다(위 2번).
- ★ **스냅숏(`ship.json`·`census.json`·`diagarg.json`)을 읽는 판정 스크립트는 입력 신선도 가드 필수**(2026-09-15, 스크립트 3개 전부 같은 병) — 원천에서 다시 계산한 결과와 다르면 rc=2, 니들·제외 목록은 원천에서 읽고 줄 번호 키 금지(`(파일, 문자열 앵커, 기대 횟수)`), 사라진 항목은 「기대 0 + 해시」로 보존, selftest에 변이 대조 3종. 정본: `docs/TEAM.md` 「기준과 대상이 같이 낡은 스냅숏」 절.
- ★ **수정 범위(리더 판정 2026-09-15)** — 디자인 공통 규칙(프로덕션 `.cs` 전면 금지)은 이 자리에 그대로 적용하지 않는다.
  **허용**: 문자열 테이블·번역 데이터 파일(`.asset`의 표시 문자열, 테이블 데이터, `docs/localization/` 산출물·판정 스크립트).
  **금지**: 문자열 조회 구조·발화 게이트 등 **프로덕션 로직 `.cs` 수정** — 설계안을 내고 구현은 `coder-systems`가 한다(게이트 계수 변경 포함).
  **`.cs` 안의 문자열 리터럴(대사·UI)**: 리터럴 교체도 `.cs` 수정이다 — 이 자리는 **교체표**(파일·앵커·원문·번역)를 내고 적용은 `coder-systems`가 한다. 문자열 테이블로 이관된 뒤의 데이터 파일 수정은 위 허용에 든다(리더 판정 2026-09-15, verify-change 경미 1).
- ★ **git**: 실저장소에서 porcelain `git diff` 금지(`--no-optional-locks`를 붙여도 인덱스를 쓴다 — 실측). 그 밖의 명령은 `docs/TEAM.md` ⑨ 「실저장소 git 허용 목록」을 따르고, 목록에 없는 명령은 쓰지 않는다. 명령·옵션을 셸 변수에 담지 마라.
- 완료 보고에 **"Windows 영향" / "macOS 영향"** 한 줄씩.

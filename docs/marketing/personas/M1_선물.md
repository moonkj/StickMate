# M1 `선물` — 남의 계정에 돈을 쓰는 사람

작성: `marketing` R3 · 근거: `_시장축_공통실측.md`

## ★ 지갑을 여는 한 문장
> **"받는 사람이 컴퓨터를 켤 때마다 내가 준 것이 화면에 있다 — 먹어 없어지지 않는 선물이라서 산다."**

## 1. 한 줄 정체
동료·친구·연인에게 스팀으로 소소한 것을 보낸다. **자기가 쓸 생각이 없다.**
고르는 기준이 "내가 좋아하는 것"이 아니라 **"받는 사람이 켜 놓고 있을 것"**이다.

## 2. 지갑의 성질 — 다른 다섯과 어디가 다른가
| 축 | M1 |
|---|---|
| 누구를 위해 내나 | **남** |
| 가격 민감도 | **낮다.** 선물은 "적당히 싼 것"이 아니라 **"적당히 성의 있는 것"**을 찾는다. $7.99대는 오히려 편한 대역 |
| 무엇을 사나 | 제품이 아니라 **"그 사람 화면에 며칠 남을 장면"** |
| 언제 사나 | 생일·입사·이직·연말. **스팀 할인 일정과 무관한 자체 캘린더가 있다** |

★ **가장 중요한 구조적 사실**: **무료 앱은 선물할 수 없다.**
F2P를 택하는 순간 이 세그먼트는 **0이 된다** — 축소가 아니라 소멸이다.
이건 마케팅 의견이 아니라 스토어 메커니즘이고, `product-strategy`의 F2P/유료 분기에 그대로 입력된다.

## 3. ★ "장비 42종이 구매 이유가 되는가"
**조건부 O.** 단 **"42종"이라는 수 때문이 아니다.**

선물하는 사람은 **자기가 고르지 않는다.** 그가 사는 것은 **"받는 사람이 자기 걸로 만들 여지"**다.
그래서 이 사람에게 유효한 문장은 *"42종"*이 아니라 **"받는 사람이 자기 캐릭터로 만들 수 있다"**다.

**그런데 여기서 실측이 정면으로 반박한다.**
- 선물을 받는 날 열려 있는 것은 **6종**이고(F-M1), 나머지 35칸은 **`???`**다.
- 선물 개봉 순간 화면이 **"레벨 4가 되면 열립니다"**로 덮여 있으면,
  **선물로서 실패**한다. 선물의 값어치는 **받은 그날 결정**되는데, 우리 콘텐츠는 75일에 걸쳐 열린다.

> **→ 이 페르소나가 만드는 유일한 실질 요구는 "42종을 홍보하자"가 아니라
> 「선물 수령 첫날 화면이 초라하지 않은가」다.** 그 판정은 내 소관이 아니다(→ 5절).

## 4. 무엇을 보고 사는가 / 어디서 걸리는가
- **본다**: 스토어 페이지 첫 스크린샷 1장. **"이걸 받으면 저 사람 화면이 저렇게 된다"**가
  1장에서 안 읽히면 다음 후보로 넘어간다. → **`SHOT_LIST.md` A-1이 정확히 이 한 장이다.**
- **걸린다 ①**: **"상주 앱을 남에게 선물해도 되나"**의 망설임.
  받는 사람 컴퓨터에 뭔가를 상주시키는 것은 실례가 될 수 있다.
  → **"권한 0 · 네트워크 0 · 소리 0 · 클릭 관통 기본 ON"**이 이 망설임을 정확히 지운다.
  **선물 세그먼트에서 신뢰 문구는 장식이 아니라 구매 조건이다.**
- **걸린다 ②**: 받는 사람이 **Windows인지 macOS인지 모른다.** 두 플랫폼 다 된다는 사실이
  스토어 페이지 상단에서 보여야 한다(스팀 OS 아이콘만으로는 약하다).
- **걸린다 ③**: **작업표시줄 자동 숨김 예외.** 남의 컴퓨터 설정을 건드린다는 고지는 선물 맥락에서
  더 크게 읽힌다. **그래도 반드시 적는다** — 숨기면 그게 선물 사고가 된다.

## 5. 버리는 조건 (무엇이 사실이면 이 페르소나가 죽는가)
1. **F2P 확정** → 즉사. 무료 앱은 선물 대상이 아니다.
2. **첫날 6종 체감이 "빈 옷장"으로 판정되면** → 선물 소구력이 절반 이하로 떨어진다.
   (판정 주체: `design-systems` 성장 곡선 + 리더. **나는 요청만 한다.**)
3. 스팀 선물 기능의 지역·친구기간 제약이 우리 주 시장에서 실질적으로 막혀 있으면 → 축소.
   **★ 미확인** — 스팀 선물 정책의 현행 제약을 나는 확인하지 못했다. 추측으로 메우지 않는다.

## 6. 대가
- 선물 문맥을 스토어 페이지에 넣으면 **문장 하나를 "쓰는 사람"이 아니라 "주는 사람"에게 쓰게 된다.**
  페이지 상단은 자리가 좁다 — M3(영어권)의 30초 설명과 **자리를 다툰다**.
- 해법 초안: 상단은 M3용으로 쓰고, **선물 문맥은 스크린샷 캡션과 연말 개발일지 1편으로만** 다룬다.

## 7. 요청 (리더 경유. 나는 다른 담당자에게 직접 지시하지 않는다)
- → **`product-strategy`**: **"F2P는 선물 세그먼트를 소멸시킨다"**를 분기 판단에 넣어 달라.
  내가 제공하는 것은 이 한 줄뿐이고, 크기 추정은 하지 않았다(**미확인**).
- → **기획·총괄**: 판단 필요 — **선물 수령 첫날 열려 있는 6종이 충분한가.**
  나는 "부족하다"고 단정하지 않는다. **잰 사실만 올린다: 7/42, 그중 1개는 「없음」.**

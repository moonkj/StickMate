# R2 `스크롤` — 짧은 영상에서 3초 보고 지나가는 사람

## 1. 한 줄 정체
소재를 **찾으러 온 게 아니다.** 자기 전에 피드를 넘기다 우연히 본다. 소리는 꺼져 있다.
이 앱이 존재한다는 것도 몰랐고, "데스크톱 펫"이라는 말도 모른다.

## 2. 어디서 만나는가
짧은 영상 피드. **`CHANNELS.md` 2-1의 구조적 이점이 오직 이 사람에게서만 현금화된다** —
이 제품은 3초 안에 설명 없이 읽히는 몇 안 되는 소프트웨어다.

## 3. 첫 3초에 무엇을 보는가
**두 가지 중 하나만 일어난다.**
- (a) "저게 뭐야?" → 손가락이 멈춘다
- (b) "스틱맨 애니메이션이네" → 넘긴다

(b)로 가면 끝이다. **(a)와 (b)를 가르는 것은 캐릭터가 아니라 배경이다.**
캐릭터가 **명백히 실제 OS 창** 위에 서 있어야 "저건 앱이구나"가 성립한다.
→ `MOMENTS.md` **C4는 이 사람 때문에 타협 불가 조건**이다.

## 4. 마음이 움직이는 지점
- **M5 창 도둑(2.7초)** — 작은 창을 끌고 가려다 낑낑대고 포기. 자막 없이 읽힌다.
- **M7 창 부수기 + 클릭 관통(3.4초)** — "부쉈는데 안 부서졌다"의 반전.
- **M1 활쏘기** — 빗나감-빗나감-정중앙. 마지막 1발이 코드로 보장돼 있어 **끝까지 보게 만든다.**

**공통점: 셋 다 "사건"이 있다.** 그냥 걷는 클립은 이 사람을 못 잡는다(`MOMENTS.md` C5).

## 5. ★ 무엇 때문에 값을 묻기도 전에 떠나는가

| # | 이탈 사유 | 우리 상태 |
|---|---|---|
| **A** | **이게 실제로 구할 수 있는 프로그램인지 모른다** | 영상만 보면 애니메이션 습작과 구분이 안 된다. **첫 프레임에 실제 OS 크롬(메뉴바/작업표시줄)이 보여야 한다** |
| **B** | **어디서 받는지 모른다** | [전략팀 확정 대기] — 스토어가 안 정해져 링크가 없다 |
| **C** | **자기 컴퓨터에서도 되는지 모른다** | macOS/Windows 표기를 소재 안에 넣어야 한다 |
| **D** | 캐릭터가 작아서 **썸네일에서 안 보인다** | `MOMENTS.md` C3. 배포 기본 배율에서 세로 360px로 줄였을 때 읽히는지 **아직 안 재 봤다 — 미확인** |
| **E** | 3초짜리 클립이 **"이게 다야?"**로 읽힌다 | 한 클립에 한 사건. 여러 기능을 몰아넣으면 오히려 진다 |

**D는 지금 확인 가능한 것이고, 확인 안 하면 소재를 다 만들고 나서 못 쓰게 될 수 있다.**

## 6. 어느 팀에 무엇을 요청하는가

**→ 디자인 (`design-character`, 리더 경유)**
- **썸네일 가독 실측 1건**: 배포 기본 배율에서 캡처 → 세로 360px / 240px로 축소했을 때
  캐릭터 실루엣과 사건이 구분되는가. 이 팀은 이미 획 두께 최소 가독 기준을 실측으로 다뤄 왔고
  (`ACCESSORY_STROKE_WEIGHT_VERDICT.md`), **같은 자를 "스크롤 거리"에서 한 번 더 대는 일**이다.
- ★ 근거: 액세서리 획 두께가 **출하 기본 배율에서 이미 최소 가독 기준 미달**이었던 실제 사고가
  있었다(`process.md` 2026-08-31). 축소하면 그 차이가 먼저 죽는다.

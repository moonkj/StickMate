# M9 `여러대` — 컴퓨터를 **세 대** 쓴다

작성: `marketing` R4 2026-09-02 밤 · 축: **시장·지갑**

> ### ★ 지갑을 여는 한 문장
> **"한 번 사면 내 세 대 전부에서 「같은 애」가 되어야 산다 — 아니면 세 번 키우라는 뜻이라 안 산다."**

---

## 1. 누구인가
회사 노트북 / 집 데스크톱 / 개인 노트북을 **오간다.** R3(`회사PC`)와 겹치는 것은 기기 하나뿐이고,
**지갑의 이유가 다르다** — R3는 *"회사 PC에 깔아도 되나"*, M9는 **"세 대에서 이어지나"**다.

## 2. ★ 이 사람에게 F2P + 유료 DLC 구조가 갖는 특수성

- 스팀 계정 기반이므로 **DLC 소유권은 세 대에서 자동으로 따라간다.** ✅ 문제없음
- ★ 문제는 **소유권이 아니라 진행도**다. 레벨·해금·착용이 안 따라오면
  **"산 옷을 새 컴퓨터에서 못 입는다"**가 된다 — 42종이 **레벨 해금**이기 때문이다
  (`Items/*.asset` `requiredLevel` 1~30, 신규 설치 시 열린 것 **7개 중 실질 6종**).

## 3. ★ 우리 상태 — 실측과 **미확인**

| 항목 | 상태 |
|---|---|
| 세이브 위치 | 로컬 파일(`stickmate_character.json` + `.prev.json` 백업). ★ 동기화 장치는 **확인하지 못했다 — 미확인** |
| Steam Cloud | ★★ **실측했다 — 없고, 게다가 감사가 막고 있다.** `Tests/EditMode/OfflineFirstNetworkAuditTests.cs:205-208`에 니들 **`"Steamworks"`**가 **금지어**로 등록돼 있고, 사유가 그대로 적혀 있다: *"5-1-10이 명시적으로 **'Auto-Cloud(코드 0줄) 경로를 권고, ISteamRemoteStorage API 방식은 권고하지 않음'**"*. `:503`은 Steam Cloud를 *"1차 출시 이후 · 조건부"*로, **리더 승인 없이 추가 불가**로 못박는다 |
| 사용자 환경 | 커밋 `aaac7b2` 기록: 사용자 환경에 **동기화 없음** |

★★ **그리고 이 실측이 4절의 딜레마를 반쯤 푼다** — 아래를 보라.

## 4. ★★ 이 페르소나 고유의 발견 — **"네트워크 0"과 정면 충돌한다**

우리의 가장 강한 문장은 이것이다:

> **"인터넷에 접속하지 않습니다. 계정도, 로그인도, 서버도 없습니다."**

**Steam Cloud를 켜면 이 문장이 흔들린다.** 기술적으로는 스팀 클라이언트가 파일을 올리는 것이지
우리 프로세스가 나가는 것이 아니지만, **구매자에게 그 구분은 안 보인다.**
그리고 M5(`신뢰구매`)는 **이 문장을 실제로 검증하는 세그먼트**다 — 틀리면 **글을 쓴다.**

| 선택 | 얻는 것 | 잃는 것 |
|---|---|---|
| ★★ **Steam Auto-Cloud** (코드 0줄) | M9의 지갑 **+ 우리 문장 유지**. 파일을 옮기는 것은 **스팀 클라이언트**이고 **우리 바이너리에는 네트워크 코드가 한 줄도 안 는다** — 그래서 *"이 앱은 인터넷에 접속하지 않습니다"*가 **여전히 문자 그대로 참**이다 | ★ 그래도 **문장을 한 줄 늘려야 한다**: *"진행도 동기화는 스팀이 합니다. 저희 앱이 직접 통신하지는 않습니다."* 이 한 줄을 안 붙이면 M5가 **트집이 아니라 정당한 지적**을 한다 |
| `ISteamRemoteStorage` API 방식 | 세밀한 제어 | ★★ **감사가 막는다**(`OfflineFirstNetworkAuditTests.cs:205`). 그리고 그 순간 위 문장이 **진짜로** 흔들린다 |
| Cloud **안 한다** | 문장이 가장 짧게 유지된다 | M9는 **세 번 키우라는 말**로 듣고 안 산다 |
| **수동 내보내기/불러오기** | 양쪽 다 유지 | 구현·UI 비용. 편의성 낮음 |

> ### ★ 마케팅 의견 (판정은 리더 / `product-strategy` / `game-architect`)
> **Auto-Cloud는 이 딜레마의 유일한 정직한 해다.** 저장소가 이미 그렇게 판단해
> **감사 테스트로 잠가 뒀다.** 마케팅이 할 일은 **그 사실을 문안에 정확히 옮기는 것**뿐이다.
> ★ 다만 **"1차 출시 이후·조건부"**이므로 **1.0 스토어 페이지에 「여러 대에서 이어집니다」를
> 적으면 안 된다.** 적는 순간 그건 로드맵 약속이 된다.

## 5. 마케팅에 주는 결론
1. **1.0에서는 「여러 대」를 소구하지 않는다.** Steam Cloud가 *"1차 출시 이후·조건부"*다.
2. ★ **위 표를 스토어 문안 확정 전에 반드시 통과시킨다.** Cloud를 켠 뒤에
   *"인터넷에 접속하지 않습니다"*를 그대로 두면 **그 순간 우리의 가장 강한 문장이 거짓이 된다.**
   순서가 뒤집히면 되돌릴 수 없다 — **스토어 페이지는 공개된 뒤에 고치면 그게 기록으로 남는다.**

## 6. 요청 (리더 경유)
- → `product-strategy`·`game-architect`(판단): 4절 4선택지. 마케팅 의견은 **Auto-Cloud**.
- → 리더(보고): Steamworks 연동 코드는 **없고**, 감사가 니들로 **막고 있다**
  (`OfflineFirstNetworkAuditTests.cs:205-208,503`). 내가 미확인으로 적었다가 같은 라운드에 쟀다.

  스팀 단독 채널 확정이므로 이 축은 **Windows에서 먼저 발생**한다.
- **macOS 영향: 없음(문서만).** 같은 판단이 macOS에도 그대로 적용된다.

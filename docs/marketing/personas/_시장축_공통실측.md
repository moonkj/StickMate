# 시장축 페르소나가 공유하는 실측 사실 (M1~M6 공통 근거)

작성: `marketing` · **R3 2026-09-02 저녁** · 전부 이 라운드에 직접 잰 값이다(기억으로 쓰지 않았다).

> 이 파일은 **읽을 문서가 아니라 근거 창고**다. M1~M6이 여기를 참조한다.
> 여기 없는 숫자를 페르소나 문서에 쓰지 않는다.

## F-M1. ★ "장비 42종"의 실체 — 이 라운드 최대 발견

`product-strategy`가 조사 중인 질문(*"장비 42종이 구매 이유가 되는가"*)에 답하려면
**42가 무엇의 42인지**를 먼저 재야 했다. 쟀다.

| 잰 것 | 값 | 방법 |
|---|---|---|
| `Assets/_Project/Resources/Items/*.asset` 개수 | **42** | `ls \| wc -l` |
| 구성 | **7 슬롯 × 6종** | 파일명 접두어 집계 |
| 슬롯 | 모자 6 / 안경 6 / 목 6 / 등(망토) 6 / 머리모양 6 / 이펙트 6 / 펫 6 | `EquipmentSlot` enum 0~6 |
| ★ 그중 **콘텐츠가 아닌 항목** | **1개** — `look_fx_none`, `displayName: "없음"` | 에셋 직접 확인 |
| 해금 방식 | **전부 레벨**(`requiredLevel` 1~30). 결제 해금 경로 **없음** | 42개 에셋 전수 + `EquipmentModel.cs` 주석 |
| ★ **신규 설치 시 열려 있는 것** | **7개** (`requiredLevel: 1`) | 42개 전수 grep |
| 그 7개의 정체 | 선글라스 / 천모자 / 나비넥타이 / 짧은망토 / 삐친머리 / 작은공 / **「없음」** | 에셋 `displayName` |
| ★ 즉 **첫날 실제로 걸칠 수 있는 것** | **6종** (「없음」은 이펙트를 끄는 선택지다) | 위 두 줄의 차 |
| 보관함 헤더에 뜨는 문자열 | `걸치는 것  (7 / 42)` | `CharacterInfoWindow.Inventory.cs:43` |
| 잠긴 항목의 표시 | 이름 `???` / 본문 **"레벨 N이 되면 열립니다. 지금은 실루엣만 보입니다."** | 같은 파일 92행·157행 |

### 이 실측이 마케팅에 강제하는 것 3가지

1. **42종 격자 스크린샷을 만들 수 없다.** 실제 신규 설치 화면은 **`???` 35칸**이다.
   전부 색이 들어간 42칸 격자를 만들면 그건 **목업이고 거짓 소재**다(정의서 ★ 2번).
   찍으려면 **레벨 30 저장 파일**이 필요하고, 그건 "우리가 보여준 화면 = 75일 뒤의 화면"이라는
   뜻이므로 **캡션에 그 사실을 적어야** 정직하다.
2. **"42종"을 헤드라인 숫자로 쓰면 우리가 지는 축으로 자진 이동한다.** 같은 카테고리 무료
   경쟁이 45종(WindowPet) · 100종 이상(Pets Therapy, 37종 영구 무료)을 말한다
   (`docs/strategy/MARKET_LANDSCAPE.md` 4절·9절 출처).
3. **구매 시점에 42종은 보이지 않는다.** 사는 사람이 보는 것은 6종이다.
   → 그래서 M1~M6 전원에게 같은 질문을 던졌고, **답이 갈렸다**(`README.md` 종합표).

### 내 지난 회 오류 1건 정정
`R4_이미써봄.md` 5절 E에 *"42종 + 8슬롯"*이라고 적었다. **슬롯은 7개다**
(`EquipmentModel.SlotCount = 7`). 표정(FACE) 카테고리가 2026-08-30에 삭제되며 8 → 7이 됐고
나는 삭제 전 숫자를 옮겨 적었다. 세지 않고 적은 것이 **두 라운드 연속**이다(R1 타일 4→5, R2 8→7).
**규율로 고친다: 이 문서의 모든 개수는 명령 출력을 붙여 넣고 쓴다.**

## F-M2. 도달 ≠ 매출 — 자릿수가 틀린 1차 사례

| 지표 | 값 |
|---|---|
| Bongo Cat 피크 동시접속 | 194,508 |
| 리뷰 | 103,833 |
| **3.5개월 실매출** | **$12,650** (3월 $2,000 / 4월 $4,050 / 5월 $3,800 / 6월 말 $2,800) |
| 개발자 진술 | *"결국 우리는 돈을 잃고 있다 — 개발자 한 명 인건비도 안 나온다"* (Marcel Zurawka) |

**리뷰 1건당 $0.12다.** 그리고 개발자 본인이 밝힌 목적은 매출이 아니라 **다음 프로젝트(Oku)의
마케팅 도구**였다 — 즉 그 도달은 **다른 상품으로 흘러갈 곳이 있었다.**

> ★ **우리에겐 흘려보낼 두 번째 상품이 없다.** 그래서 이 사례는 우리가 따라 할 모델이 아니라
> **경고**다. 도달 지표를 매출로 환산하는 문장을 마케팅 산출물에 쓰지 않는다(`CHANNELS.md` 6절).

## F-M3. 오늘 확정으로 바뀐 전제 (리더 브리핑 2026-09-02)

| 확정 | 페르소나에 미치는 영향 |
|---|---|
| **MS 스토어 제외 / 스팀 단일** | `MARKET_PERSONAS_PURCHASE.md` P1(사내 표준 PC)의 유일한 통로가 닫혔다 → **M 계열에서 그 계층을 세지 않는다** |
| **DLC 1.0 포함** | 출시일에 팔 것이 둘이다 → M1(선물)·M4(코스메틱 지불 이력)가 **출시일부터** 유효 |
| **영어 1.0 포함** | M3(영어권)이 **가정이 아니라 대상**이 된다. 영어가 스팀 폴백 언어 |
| **플러그인 봉인(1st-party 전용)** | 커뮤니티 모드 서사 불가 → **M5(신뢰 구매자)의 근거가 오히려 깨끗해진다**(남의 코드가 안 들어온다) |
| **코드서명: 필수 → 선택** | ★ **M5에게만은 여전히 필수다.** 5절에서 반대 입력으로 올린다 |
| 모바일 추후 / 「이벤트」 탭 폐지 | 소재·기능 목록에서 제외 |

## F-M4. 아직 미확인이라 페르소나가 기대어선 안 되는 것

- **출하 빌드의 아웃바운드 트래픽 0** — `ProjectSettings.asset:93 submitAnalytics: 0` 확인.
  하지만 이건 **에디터 설정 한 줄**이고, `Packages/manifest.json:28`에는
  `com.unity.modules.unityanalytics` 모듈이 여전히 들어 있다(빌트인 모듈이라 존재 자체는
  정상이지만, **"네트워크 0"을 말하려면 출하 바이너리에서 재확인**해야 한다).
- **가격·묶음** — `product-strategy` 소관. M 계열은 "얼마"를 정하지 않고 **"무엇 때문에 여는가"**만 쓴다.
- **성능 수치** — 인용 금지(`TRUTH_INVENTORY.md` 6절). M2가 이 항목에 걸리지만 숫자는 안 쓴다.

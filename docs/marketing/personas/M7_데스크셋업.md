# M7 `데스크셋업` — 자기 바탕화면 **정지 이미지**를 올리는 사람

작성: `marketing` R4 2026-09-02 밤 · 축: **시장·지갑**

> ### ★ 지갑을 여는 한 문장
> **"내가 올릴 한 장에, 남들 셋업에는 없는 게 하나 있어야 해서 산다."**

---

## 1. M2(`보여주는사람`)와 무엇이 다른가 — **매체가 다르면 요구가 다르다**

| | M2 `보여주는사람` | **M7 (이 문서)** |
|---|---|---|
| 매체 | **실시간 영상** | **정지 이미지 한 장** |
| 가치 | *"저거 뭐예요?"* 라는 **질문** | *"이 셋업 좋다"* 라는 **좋아요** |
| 필요한 것 | **매일 다름**(변주) | ★ **한 장에서 완성될 것**(구도) |
| 캐릭터가 움직이는 것 | 콘텐츠의 핵심 | ★ **무관하다.** 정지컷에는 안 찍힌다 |
| 치명적 결함 | 사라짐 | ★ **배경에 묻힘** |

**같은 사람이 아니다.** M2에게 물리는 최대 자산이고, **M7에게 물리는 정지컷에 안 찍힌다.**

## 2. 이 사람이 사는 것

**"내 화면 스크린샷의 완성도"**를 산다. 그래서 판단 기준이 셋뿐이다:

1. **작은 크기에서 실루엣이 읽히는가** (셋업 사진에서 캐릭터는 화면의 2~5%다)
2. **내 배경화면 색과 싸우지 않는가**
3. **내가 원하는 자리에 둘 수 있는가**

## 3. ★ 우리 상태 — 실측

| 항목 | 상태 | 근거 |
|---|---|---|
| 미니멀한 조형 | ★ **강점.** 획 기반 스틱 형태라 어떤 배경화면과도 덜 싸운다 | `docs/CHARACTER_FORM_SPEC.md` |
| 소리 0 | 무관(정지 이미지) | — |
| ★★ **밝은 배경에서 장비가 사라진다** | ★★ **치명적.** 출하 27색 중 **21색**이 몸에 칠한 뒤 배경 4종 중 하나 이상에서 대비 3.0 미달. 최악 `#FFF0B8` → 몸 `#CCBA76` = **1.60 : 1** | `TRUTH_INVENTORY.md` 4절(D등급) |
| ★ **"내가 원하는 자리에 둘 수 없다"** | 캐릭터는 **자율 배회**한다. 위치를 고정하는 수단이 없다 | `DefaultStickConfig.asset` 배회 파라미터 전반 |
| 톱니 아이콘이 화면에 남는다 | **끌 수 있다** — 끄면 진입점이 단축키만 남는다 | `SettingsWindow.cs` `general.gearIcon` 토글 + 경고 캡션 |

## 4. ★ 이 사람이 발견한 것 (M7 고유)

> **"셋업 사진을 찍는 순간에는 캐릭터가 「지금 여기」에 있어야 한다."**

M2는 캐릭터가 **돌아다녀야** 콘텐츠가 되고, M7은 **멈춰 있어야** 사진이 된다.
지금 우리에겐 **후자를 위한 수단이 하나도 없다.**

★ **그런데 마케팅으로서 이건 기능 요구가 아니다.** 요구하면 "먼저 나서지 않는다"는
제품 정체성과 충돌하는 방향으로 갈 수 있다. **판단은 기획 소관**이고, 나는 사실만 올린다.

## 5. 마케팅에 주는 결론

1. ★ **소재에 「바탕화면 스크린샷 한 장」을 반드시 넣는다.** 지금 우리 소재 계획
   (`CAPTURE_REQUESTS_R4.md`)은 **전부 움직임**이다 — 물리·통과·물러남. **한 장짜리가 P3 하나뿐**이다.
2. **P3(`S-1`)를 「셋업 사진처럼」 찍는다** — 어수선한 창 배치가 아니라 **정돈된 화면**으로.
   그러면 같은 컷이 M7에게도 작동한다. **새 촬영이 아니라 구도 지시 한 줄**이다.
3. **장비 컷은 여전히 보류**(D등급). 이 사람에게 대비 미달은 결함이 아니라 **구매 이유의 소멸**이다.

## 6. 요청 (리더 경유)
- → `design-art`(참고): 27색 대비 수정이 끝나면 **밝은 배경화면 위 소형 표시**를 판정 조건에 넣어 달라.
  이 사람이 보는 크기는 화면의 **2~5%**다.
- → 리더(판단): **"위치를 정할 수 있는가"**는 기능 축이다. 나는 요구하지 않고 사실만 올린다.

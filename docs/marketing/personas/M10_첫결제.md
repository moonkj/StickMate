# M10 `첫결제` — 무료로 한 달 쓴 뒤에 처음 지갑을 여는 사람

작성: `marketing` R5 2026-09-03 · **본편 무료(F2P) 확정으로 신설**

> ### ★ 지갑을 여는 한 문장
> **"한 달을 같이 산 애한테 5천 원을 쓰는 건 새 앱을 사는 게 아니라
> 이미 내 것인 걸 조금 더 해 주는 것이라서 연다."**

---

## 0. 왜 이 페르소나가 **새로운가** — 축이 「누구」가 아니라 「언제」다

M1~M9는 전부 **구매 결정이 스토어 페이지에서 일어난다**고 전제한다. 유료였으니 당연했다.
**F2P는 그 전제를 깬다.**

| | M1~M9 (유료 전제) | **M10 (F2P)** |
|---|---|---|
| 결정 장소 | **스토어 페이지** | ★ **앱 안, 설치 며칠~몇 주 뒤** |
| 결정 재료 | 스크린샷 · 설명 · 리뷰 | ★ **자기가 이미 쓴 시간** |
| 마케팅이 할 일 | 설득 | ★ **설득이 아니라 「그 순간에 그 자리에 있기」** |

★ **그래서 M10은 기존 페르소나 누구와도 안 겹친다.** 같은 사람이 M3(`영어권`)이면서
동시에 M10일 수 있다 — **축이 다르기 때문**이다.

---

## 1. 이 사람의 실제 경로

```
스토어 페이지 (30초, "무료네" → 설치)
   → 첫날: 신기함
   → 3~7일: 익숙해짐          ← ★ 여기서 대부분이 조용히 사라진다(R4 `이미써봄`)
   → 2~4주: 배경이 됨          ← ★★ M10이 갈리는 지점
   → 어느 날 "얘 좀 바꿔 줄까"  ← 첫 결제
```

★ **핵심 관측**: 이 사람이 지갑을 여는 이유는 **팩이 좋아서가 아니라 애착이 이미 있어서**다.
**팩은 애착을 만들지 않는다. 이미 있는 애착을 쓰는 것이다.**
⇒ **팩 문구가 「이게 얼마나 좋은지」를 말하면 이 사람에게 안 닿는다.**

## 2. 무엇이 이 사람을 **잃게 하는가** (전부 실측 근거 있음)

| # | 잃는 지점 | 근거 |
|---|---|---|
| **L1** | ★★ **2~4주 사이에 「투명해진다」** — 질리는 게 아니라 **안 보이게 된다.** 상주 앱의 진짜 사망 원인 | `personas/R4_이미써봄.md`의 이탈 형태(*"일주일 만에 지웠다"*) |
| **L2** | **첫 주에 「안 사면 뒤처진다」를 느끼면 그 자리에서 끝난다.** F2P 최대 이탈 사유 | 우리는 구조적으로 그게 없다 — `ECONOMY_SPEC` 2-4 **3중 방어**(설계 확정 · 코드 0줄) |
| **L3** | **첫 결제 화면이 앱 안에 없으면 결제 자체가 안 일어난다** | ★ **미확인** — 앱 안에 팩 진입점이 있는지 나는 확인하지 못했다. `DlcPack`/`PackManifest` **프로덕션 참조 0건**이므로 **오늘은 없다** |
| **L4** | **팩이 옷만 들었으면 첫날 갈아입히고 끝** | `product-strategy` P-0과 같은 결론 |

## 3. ★ 이 사람이 마케팅에 요구하는 것

| 요구 | 지금 상태 |
|---|---|
| **스토어 페이지가 팩을 길게 설명하지 않을 것** — 설치도 안 한 사람에게 결제를 권하면 첫인상이 나빠진다 | ★ **반영됨** — `STORE_PAGE.md` 규칙 S-1 · S-2 |

| ★ **팩이 대사·모션을 바꿀 것**(L4) | ★ **`design-narrative`/`design-motion` 영역.** 리더 경유 |

## 4. ★ 아이디어 — **「첫 결제의 순간」을 어디에 둘 것인가** (판매 전략)

> **아이디어**: 팩 진입점을 **「상점」이 아니라 「보관함(걸치는 것)」 안에** 둔다.
> 이미 열려 있는 42종 옆에 잠긴 팩 항목이 **같은 격자**로 보이는 형태.

- **근거**: 이 앱은 이미 **레벨 해금 격자(`???` 표시)**를 갖고 있고, 사용자는 *"기다리면 열리는 것"*에
  **이미 익숙하다**(보관함 헤더 `걸치는 것 (7 / 42)`, 잠긴 항목 *"레벨 N이 되면 열립니다"*).
  **결제 해금을 그 옆에 두면 새 개념을 배울 필요가 없다.**
- **대가**: ★ **레벨 해금과 결제 해금이 같은 격자에 섞이면 「돈으로 레벨을 산다」로 읽힐 수 있다.**
  그건 `ECONOMY_SPEC`의 「현금↔재화 다리 없음」과 정면으로 어긋나 **보인다**(실제로는 아니지만
  **보이는 것이 문제다**). 시각적으로 확실히 갈라야 하고 그건 `ux-designer`/`design-art` 비용이다.
- ★ **버리는 조건**: 사용자가 확정한 **"현금↔재화 다리 없음"**과 충돌한다고 리더가 판정하면 폐기.
  그리고 **잠긴 팩 항목이 「팔려고 잠가 둔 것」으로 읽힌다는 사용자 반응이 나오면 즉시 폐기** —
  그 순간 2-2절 「대가가 없습니다」가 통째로 무너진다.

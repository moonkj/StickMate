## 0. 먼저 — 이 앱의 척추 문장

> **"어떤 OS 권한도 요구하지 않는다."**

이건 마케팅 카피가 아니라 **실측된 구조 사실**이고, 이 앱이 시장에서 가진 유일하게 방어 가능한
차별점이다. 근거를 한 자리에 모은다.

| 주장 | 근거 (파일:행) | 검증 방식 |
|---|---|---|
| macOS는 창 **제목**을 읽지 않는다. 앱 이름(`kCGWindowOwnerName`)과 bounds만 읽는다 | `Platform/MacOS/MacWindowService.cs:465,608` (UX_FLOW 35-2-1이 전수 확인) | 소스 |
| 접근성 권한 / 화면 기록 권한 / 관리자 권한 **불필요** | `MacWindowService.cs:102,110,213,248`, `Windows/Win32WindowService.cs:153` | 소스 주석 + 실기 구동 |
| 네트워크 API 사용 **0건**. 전송 화이트리스트가 **비어 있음** | `Tests/EditMode/OfflineFirstNetworkAuditTests.cs` | **자동 검사 10건 + 네거티브 컨트롤 4건** |
| 타 창을 이동·크기변경·종료·포커스강제하는 메서드가 인터페이스에 **없다** | `Tests/EditMode/UserAssetImmutabilityAuditTests.cs` | **자동 검사 9건 + 네거티브 컨트롤** |
| 레지스트리 쓰기 API가 저장소 전체에 **없다** | 같은 파일 (`레지스트리_쓰기_API가_저장소_어디에도_없다`) | 자동 검사 |

**★ 검사에 네거티브 컨트롤이 붙어 있다는 점이 핵심이다.** "0건이라 초록"이 아니라 "일부러 위반
코드를 넣으면 빨개진다"까지 검증돼 있다. 이건 개발일지에 그대로 쓸 수 있는 서사다(3절 참고).

### 0-1. 승인된 예외 1건 — **반드시 함께 말한다**

Windows에서 **작업표시줄 자동 숨김 비트 하나**를 실행 중에만 끈다(종료 시 원복, 크래시 시 다음
실행이 복구). 사용자 확정 결정이고 근거는 `docs/TASKBAR_REVEAL.md`.

> **홍보에서 이걸 숨기면 그 순간 위 표 전체가 거짓말이 된다.** 스토어 페이지 기능 목록에
> 한 줄로 명시할 것. 문안 초안: *"Windows에서 작업표시줄을 자동 숨김으로 쓰신다면, 실행 중에만
> 자동 숨김을 해제하고 종료할 때 원래대로 되돌립니다. 원래 안 쓰시는 분에게는 아무 일도
> 일어나지 않습니다."* (마지막 문장은 실제 코드 거동이다 — 시스템 쓰기 0회, 디스크 흔적 0개.)

## 2. B등급 — 된다. 단 **사용자가 시켜야** 한다 (기본 확률 0)

배포 에셋 실측: `windowTheftChance 0` / `graffitiChance 0` / `windowCrashChance 0` /
`archeryChance 0` / `desktopTidyChance 0` / `blackholeChance 0` / `todoReminderChance 0` /
`stressSulkyChance 0` / `wanderPostIdleJumpChance 0` / `wanderEdgeJumpAttemptChance 0`.

> ★★ **이건 버그가 아니라 제품 결정이다.** 사용자가 반복 요구해서 이렇게 됐다
> (`StickConfig.archeryChance` 주석, UX_FLOW 35-5 #6). 그러니 **"가만히 두면 화살을 쏩니다"는
> 거짓이다.** 대신 진실이 더 잘 팔린다:
>
> > **"먼저 나서지 않습니다. 시키면 합니다."**
>
> 이건 경쟁 데스크톱 펫과의 실질적 차별점이고, "일하는 화면에 두는 것"이라는 포지셔닝과 정확히
> 맞물린다. 소재에서 반드시 **[행동 명령] 창을 눌러 시키는 장면**과 함께 보여줄 것.

사용자 경로: **톱니 → 부채꼴 ④ [행동] → 행동 명령창(480×508)** — 타일 4개.
`Interaction/ActionCommandPopover.cs`. 실행 불가 시 회색 + **왜 안 되는지 이유 문장**을 표시하며,
그 판정은 실제 실행 판정과 **같은 함수**에서 나온다(`CommandAvailability`).

| 타일 | 실측 길이 | 소재 가치 |
|---|---|---|
| 활쏘기 | **6.14~8.03초** (접근 별도 0~12초) | ★★★ 2절 M1 |
| 그라피티 | 유지 3~5초 + 페이드아웃 0.8초 (창 침범 시 0.18초 취소) | ★★ 빈 바탕화면 96px 영역 필요 |

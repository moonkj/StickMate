### 1-3. ★ 관리자 권한 게임 · 안티치트 게임에서 실패가 「항상」 나는가 — **판정 불가(실기)**

**시간 산술 — 갈래 (가)** (코드 산술 + 두 시계 모형, 실기 미확인. 유지 1.0초)
- **두 시계**: 폴링은 float `Time.deltaTime` 누적이다(`StickmanAgent.cs:1547-1550`, 넘친 몫 버림). 캐시 비교는 double `Time.realtimeSinceStartupAsDouble`로 「실제 경과 < 30.0」이면 조회하지 않는다(Windows `WindowsGameProcessProbe.cs:128`·`:130` · macOS `MacWindowService.cs:1600-1601`).
- t0: 캐시 만료 뒤 첫 폴링에서 조회 실패 → raw false가 후보가 된다.
- t1(다음 폴링): 1.0초 이상 → 확정 → `Resume`. **등급 1 시작 = t1.**
- 캐시가 실패값을 유지한다. 폴링은 계속 돌지만 조회하지 않는다.
- t0부터 실시간 경과가 30초 이상인 첫 폴링 tk에 재조회 → 성공하면 raw true → 다음 폴링 tk+1에 확정 → `Suspend`.
- ⇒ **노출 = 실패 시각부터 실시간 경과가 30초 이상이 되는 첫 폴링까지의 폴링 수(k) × 실제 폴링 간격.** 정확히는 t1부터 tk+1까지 폴링 간격 k개의 합이다.
- 실제 폴링 간격은 1.5초에 닿는 프레임 수 × 프레임 길이다. 넘친 몫을 버리므로 보통 1.5초보다 프레임 한 칸 이하만큼 길고, 그 차이가 20번 누적돼 노출이 30초보다 길어진다(아래 표 — 30.060606060606062초(165Hz)부터 30.66666666666667초(macOS 60Hz 30fps)까지).
- 폴링 간격이 캐시 길이를 정확히 나누면(20 × 간격 = 30.0) 20번째 폴링이 캐시 경계에 걸린다. 실시간 읽기 시점이 조금만 달라도 한 폴링 늦어져(k = 21) **31.5초**가 된다.
- ⇒ **노출 약 30초 — 범위 30.0–31.5초, 실기 미확인.**

  - macOS: `macVSyncInterval: 2`(`DefaultStickConfig.asset:418`) → `FramePacing.cs:1135` vSyncCount 2 = **60Hz 화면에서 30fps**, 120Hz에서 60fps.

### 4-1. ★ FC-1 확장 설계 — 판정 실패 비캐시 + 게임바 목록 실패 비캐시 (리더 판정 · 구현 금지 · 설계만)

**재시도 규칙 — 리더 판정(2026-09-15): 실패하면 시간 비교 없이 다음 폴링에서 1회 다시 묻는다.**
- 이유: 디바운서는 바뀐 값이 1.0초 이상 이어져야 확정하므로(`FullscreenSuspendPolicy.cs:497`), 실패 뒤 바로 다음 폴링에 성공하면 후보가 버려져(`:483`) 등급이 안 바뀐다. 두 시계 모형에서 한 폴링 실패는 200/200 흡수됐다(Windows 30 → 60 · macOS 15 → 30 · 30fps · 32fps 각각, 읽기 지터 0–0.2ms · Windows는 프레임 길이 ±1ms 가정도 200/200).
- **기각 — 「N ≤ I」를 시간 비교로 구현하는 것.** `지금 - 마지막 시도 < N`(N = I = 1.5초)이면 기다리게 하면, 두 시계에서 실제 경과가 1.5초에 조금 못 미치는 폴링에서 재시도가 한 폴링 밀린다. 그러면 두 번째 false 관측이 디바운서를 확정시켜 **노출 3.0초**가 난다.
  - 모형: 정확한 이진 간격(32fps) + 읽기 지터에서 127/200 시드가 3.0초 노출(verify-change 130/200과 같은 방향).
  - Windows 60fps 격자(간격 91프레임 = 1.5166…초)와 macOS 60Hz(46프레임)에서는 0/200이었다. 프레임 길이 ±1ms 가정에서는 1/200(3.0074926736795646초)이다.
  - 즉 폴링 간격이 1.5초에 붙을수록 난다. 시간 비교를 두지 않으면 이 경계 자체가 없다.
- 예시: 재시도 간격을 시간 N = 3초로 두면 흡수하지 못하고 **노출 3.0–4.5초**다(모형: 32fps + 지터 3.0 ×95 · 4.5 ×105 / Windows 3.0333333333333314 / macOS 60Hz 3.066666666666663).

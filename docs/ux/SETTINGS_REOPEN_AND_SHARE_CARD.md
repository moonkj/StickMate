2. **F5-B는 메모 카드가 캐릭터 축(`IsSuspended`)을 읽게 만든다.** 이 형태는 리마인더·크랙과 같은 호출형이라 N-20 스캔 분류(#7 Unsummoned)를 바꾸지 않는다. ★ 다만 누군가 `HidesScreenSurfaces` 정의를 넓히는 방식으로 구현하면 09-03 축 분리 전체(톱니·설정 창·임대 만료·Windows 항상위 워치독)가 되돌아간다. **소비자에서 고친다**는 조건을 배정문에 적어 주기 바란다. ★ 2판: 리더 판정 A로 지금은 착수하지 않는다.
3. 권고안 둘 다 **N-8 목록 파일의 코드를 바꾸지 않는다.** F5-B의 로그 한 줄만 목록 파일(`StickmanAgent.cs`)이다 → 미룬다(2-5 표).
4. ★ 2판: **K3′는 자동 재오픈의 규칙을 「무장 축 = 대기 축」 하나로 줄인다.** K2의 가상 데스크톱 예외(3-6-2 (ii))는 `StickmanAgent`에 축 4 공개 읽기를 요구한다 — N-8 B 파일이라 E-3 소비 뒤에만 가능하다.
5. ★ 3판: **K3′ 구현 조건은 스캔 계약에 걸려 있다.** 스캔은 `if` 머리 단위로 유효 호출과 대체 값 읽기를 본다(`UnsummonedSurfaceAxisTests.cs:412-424`). 해제 조건을 유효 호출과 같은 머리에 두면 통과한다. 같은 판단을 지역 변수로 옮기면 스캔이 보지 못한다(사각지대). 사각지대를 스캔으로 막을지는 test-engineer 판단 사항이다.

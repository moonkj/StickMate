# Handoff: 캐릭터 정보창 (브라스 아카이브)

장비 · 외형 · 보관함 · 상점 4탭

StickMate (moonkj/StickMate) 데스크톱 컴패니언의 캐릭터 정보창 리디자인 — **장비 / 외형 / 보관함 / 상점** 4탭.
채택 시안은 **1a 「브라스 아카이브」** 하나입니다. 참조 파일에는 비교용 시안 `1b 「네온 콘솔」`도 함께 들어 있으나 **구현 대상이 아닙니다**.

## Overview

기존 장비창의 문제는 (1) 아이템 아트 퀄리티, (2) 착용 상태 가독성, (3) 스탯/세트/재화 같은 게임화 정보가 화면에 전혀 없다는 점이었습니다.
리디자인은 한 화면에서 다음을 모두 처리합니다.

- 졸라맨 캐릭터에 장비가 실제로 착용된 프리뷰
- 4개 슬롯 착용 현황 + 슬롯별 주스탯 기여도
- 4스탯 총합 · 임계 3단계 · 단계별 해금 효과
- 테마 세트 진행도와 활성/비활성 효과
- 등급·주스탯·부스탯·테마·가격이 카드에서 바로 읽히는 아이템 그리드
- 동전 재화, 상점 탭 진입점, DLC 전용 아이템 구분

## About the Design Files

`reference/` 안의 파일은 **HTML로 만든 디자인 레퍼런스(프로토타입)** 입니다. 그대로 제품에 넣는 코드가 아닙니다.
StickMate는 Unity 기반(`MotionPluginSO` / `EffectPluginSO` / `DialogueIntent` 플러그인 구조)이므로, 이 문서의 수치·색·동작 규칙을 **Unity UI(UGUI 또는 UI Toolkit)로 재현**해 주세요. HTML/CSS를 이식하는 작업이 아니라, 명세를 보고 기존 환경의 패턴으로 다시 만드는 작업입니다.

파일 열기: `reference/equipment-screen.dc.html`을 브라우저에서 열면 됩니다(외부 의존성은 웹폰트 CDN뿐). 카드 클릭 → 상세 갱신, 착용/해제 버튼 → 프리뷰·스탯·세트 즉시 반영까지 동작합니다. `ItemIcon.dc.html`은 16종 아이템 벡터 아트 정의입니다.

## Fidelity

**High-fidelity.** 색·타이포·간격·라운드·상태색이 모두 확정값입니다. 아래 수치대로 구현해 주세요.
단, 아이템 아트는 **벡터 도형 프로토타입**입니다 — 최종 아트는 팩별 아트 리소스로 교체될 것을 전제로, 실루엣/무게중심/등급 색 적용 방식만 참고하세요.

## 데이터 모델 & 규칙 (기획 5장 반영)

### 슬롯 → 주스탯 매핑

| 슬롯 | 주스탯 | 임계 효과 (초급 / 중급 / 고급) |
|---|---|---|
| 모자 | 집중력 | 성과물 배율 +10% / 명상 유휴 연출 해금 / 성과물 배율 +25% · 졸음 연출 |
| 안경 | 관찰력 | 활쏘기 쿨다운 −10% / 궤적 잔상 이펙트 / 쿨다운 −25% · 잔상 강화 |
| 넥타이 | 매력 | 오라 이펙트 발현 / 오라 범위 확대 / 오라 강도 최대 · 팩 색 연동 |
| 망토 | 민첩 | 이동속도 +8% / 던지기 최소 회전 보장 / 이동속도 +18% · 트레일 이펙트 |

- 아이템은 **주스탯 1 + 부스탯 1** 보유. 부스탯은 다른 3스탯 중 하나
- 등급별 주스탯: 일반 3 / 희귀 6 / 영웅 10 / 전설 15
- 등급별 부스탯: 일반 1 / 희귀 2 / 영웅 4 / 전설 6
- **총 스탯 = 레벨 기본치 + 현재 착용 4종 합계** (보유 아이템 수와 무관, 누적 없음)
- 레벨 기본치(Lv.7 예시): 집중력 8 / 관찰력 6 / 매력 5 / 민첩 7
- 임계 3단계: **초급 10 / 중급 20 / 고급 32**, 게이지 상한 40
- 임계로 열린 일반 행동·연출은 **영구 해금** (장비를 바꿔 스탯이 내려가도 유지) → UI는 "현재 단계"만 표시하고 해금 취소 표현은 하지 않음
- 민첩은 파쿠르 성공률에 관여하지 않음 (성공률 문구를 UI에 넣지 말 것)

### 등급

카드/상세 등급색: 일반 `#8A8F98` / 희귀 `#6E9BE8` / 영웅 `#B07BE0` / 전설 `#E0B24A`

### 테마 세트

- 팩 6종: 오피스 워커(기본) · 사이버 아포칼립스 · 네온 낙서 · 스포츠 이펙트 · 컬러 잉크 · 밀리터리
- 패널은 **착용 중 아이템의 우세 테마**를 기준으로 진행도(N/4)를 보여줌
- 부분 착용: 개별 플레이버만 활성
- 세트 완성(동일 테마 4부위 착용 중): 대사 풀 전환 + 연출 스킨 교체 + 스탯 총합 보너스(+8)
- **세트 효과는 영구 해금이 아님** — 세트를 풀면 즉시 비활성, 기본 중립 대사로 폴백

## Interactions & Behavior

- **카드 클릭** → 선택 상태로 전환(보더 `#4A4036`), 좌측 상세 카드 내용 갱신. 미보유 아이템도 선택·열람 가능
- **착용 버튼** → 같은 슬롯의 기존 아이템을 대체(1슬롯 1아이템). 이미 착용 중인 아이템의 버튼은 해제로 동작(토글)
- 착용/해제 시 즉시 갱신되는 것: 캐릭터 프리뷰 오버레이, 착용 현황 4행, 4스탯 총합·게이지·단계 칩·효과 문구, 테마 세트 진행도와 활성 행, 헤더 보유 수
- **미보유 아이템의 착용 버튼은 무효** (구매 플로우로 연결)
- hover: 카드 `translateY(-3px)` / 버튼 `brightness(1.15)` / 비활성 탭 글자색 상승
- **임계 단계 상승 순간**: 캐릭터 레벨업과 구분되는 짧은 반짝임 이펙트 1회(기존 파티클 애셋 재사용). 프로토타입에는 미구현 — 구현 시 스탯 카드의 단계 칩에도 0.4초 하이라이트를 함께 주는 것을 권장
- 컬럼 3만 세로 스크롤(스크롤바 8px, thumb `#2A2622`, 트랙 투명)

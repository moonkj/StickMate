# StickMate 사용 설명서 — 2장. 처음 켰을 때

1장을 먼저 읽으십시오. 1장은 조작을 시작하는 곳을 설명합니다.
이 장은 **처음 켠 순간부터 무엇이 보이고 무엇이 보이지 않는가**를 설명합니다.

---

## 1. 켠 직후 화면에 있는 것

StickMate를 처음 실행하면 바탕 화면 위에 **한 가지만** 나타납니다.

| 무엇 | 어디 |
|---|---|
| 캐릭터 | 화면 아래쪽 |

톱니바퀴 아이콘은 평소에는 없습니다(캐릭터를 직접 숨겼을 때만 나타납니다 — 1장 2-4).
**조작은 캐릭터를 마우스 오른쪽 버튼으로 눌러 시작합니다**(1장 2절).

**창은 하나도 열리지 않습니다.** 환영 화면도 없고, 설정 마법사도 없고, 계정 가입도 없습니다.
안내 문구도 이 시점에는 나오지 않습니다 (아래 4절을 보십시오).

**나타나지 않는 것**

- macOS Dock 아이콘
- macOS 메뉴 막대 아이콘
- Windows 작업 표시줄 버튼 — 켠 직후 StickMate가 스스로 지웁니다(1장 1-1)
- 앱 전환기(`⌘Tab` / `Alt+Tab`)의 StickMate 항목 — **양쪽 운영체제 모두**
- 톱니바퀴 아이콘 — 평소에는 없습니다(1장 2-4)

**Windows에서는 작업 표시줄에 하나 더 나타납니다 — 시스템 트레이 아이콘입니다.**
시스템 트레이는 작업 표시줄 오른쪽 끝, 시계 근처의 아이콘 자리입니다.
아이콘이 보이지 않으면 위쪽 화살표 `^`를 누르십시오. Windows 11에서는 처음부터 그 안에 들어가 있을 수 있습니다.
이것이 Windows에서 앱이 켜져 있는지 확인할 수 있는 자리입니다.
아이콘을 오른쪽 클릭하면 `캐릭터 숨기기` · `설정 열기` · `StickMate 종료` 메뉴가 열립니다(1장 1-2).
그 밖의 조작은 캐릭터를 오른쪽 클릭해 펼치는 버튼 5개로 합니다.

> 작업 표시줄 버튼을 지우는 동작이 실패하는 컴퓨터에서는 버튼이 남을 수 있습니다.
> 그 버튼은 눌러도 아무 일도 일어나지 않습니다.

### 1-1. 처음 5초 동안은 클릭이 다르게 동작합니다

앱을 켠 뒤 **약 5초 동안** 화면 클릭이 StickMate로 갑니다.
5초가 지나면 캐릭터가 그려진 부분을 뺀 나머지가 모두 아래 앱으로 지나가게 바뀝니다.

**5초만 기다리십시오.** 이것은 고장이 아닙니다.

### 1-2. Windows — 실행하는 동안 작업 표시줄 자동 숨김이 풀립니다

**이 절은 Windows에만 해당합니다.** macOS의 Dock은 건드리지 않습니다.

Windows에서 **작업 표시줄 자동 숨김을 쓰고 있다면**, StickMate를 실행하는 동안
작업 표시줄이 **숨지 않고 계속 보입니다.** 앱을 끄면 원래대로 다시 숨도록 만들어져 있습니다.

| 상황 | 무엇이 일어나는가 |
|---|---|
| 자동 숨김을 **쓰고 있다** | 실행하는 동안 자동 숨김이 꺼집니다. 종료하면 다시 켜지도록 만들어져 있습니다 |
| 자동 숨김을 원래 **안 쓰고 있다** | **아무 일도 일어나지 않습니다.** 작업 표시줄 설정을 바꾸지 않고, 되돌리기 기록 파일도 만들지 않습니다 |
| macOS | 해당 없습니다. Dock 설정은 그대로입니다 |

바뀌는 것은 **자동 숨김 한 가지**입니다. 작업 표시줄의 위치도, 크기도, 그 안의 아이콘도
옮기거나 지우지 않습니다.

**앱이 비정상 종료된 경우** — 작업 표시줄이 보이는 채로 남을 수 있습니다.
**StickMate를 한 번 더 실행하면** 시작할 때 원래 설정으로 되돌리도록 만들어져 있습니다.
기다리지 않고 지금 돌려놓고 싶다면, Windows 설정에서 자동 숨김을 직접 켜도 됩니다.
그렇게 해도 다음 실행은 평소처럼 동작하도록 만들어져 있습니다.

**StickMate를 지우려고 한다면** 먼저 1장 6-1을 읽으십시오.

> 원래 설정 값은 저장 폴더의 작은 파일 하나에 적힙니다(3-1).
> 앱이 갑자기 꺼져도 다음 실행이 그 파일을 보고 되돌리기 위한 것입니다.

## 2. 처음에 캐릭터가 가진 것

저장 파일이 없을 때 캐릭터는 아래 상태에서 시작합니다.
값은 캐릭터를 오른쪽 클릭 → **[캐릭터]** 버튼으로 여는 캐릭터 정보 창에서 볼 수 있습니다.

| 항목 | 처음 값 |
|---|---|
| 이름 | `스틱메이트` |
| 레벨 | 1 |
| `EXP` 막대 | `0 / 100` |
| `STRESS` 막대 | `0%  ·  안정` |
| 근속 | `1일차` |
| 함께한 시간 | `0분` |
| 보유 장비 | `7 / 42종` |
| 활쏘기 명중 | `기록 없음` (회색 글자) |
| 지금 무엇을 하는지 | `지금  ·  가만히 있는 중` 또는 `지금  ·  걷는 중` |

- **이름은 바꿀 수 있습니다.** 캐릭터 정보 창에서 이름을 누르고 고치십시오. 최대 12자입니다.
  이름을 비우면 `스틱메이트`로 돌아갑니다.
- `기록 없음`과 `아직 없음`은 **회색으로** 나옵니다. 값이 0이라는 뜻입니다.
  0을 숫자로 보여주면 성취처럼 읽히기 때문에 글자로 대신합니다.

### 2-1. 처음부터 가진 장비 7개

장비는 42종이고, 그중 **7종을 처음부터 가지고 있습니다.** 카테고리마다 한 개씩입니다.

| 카테고리 | 처음부터 가진 것 |
|---|---|
| 모자 | 천모자 |
| 안경 | 선글라스 |
| 넥타이 | 나비넥타이 |
| 망토 | 짧은망토 |
| 머리 | 삐친머리 |
| 이펙트 | 없음 |
| 펫 | 작은공 |

**처음부터 착용하고 있는 것은 2개입니다** — 모자의 `천모자`, 안경의 `선글라스`.
나머지 5개는 **가지고 있지만 착용하지 않은** 상태입니다.

> 이유: 기본값이 캐릭터의 생김새를 바꾸면 "내가 안 했는데 달라졌다"가 되기 때문입니다.

### 2-2. 나머지 35종은 레벨로 열립니다

아직 못 가진 카드는 `Lv.5에 열림`처럼 **몇 레벨에 열리는지 카드에 적혀 있습니다.**
가장 낮은 것이 `Lv.5`, 가장 높은 것이 `Lv.30`입니다.

**상점에서 사는 것이 아닙니다.** 지금 이 앱에는 구매 버튼이 하나도 없습니다.
레벨이 오르면 열립니다.

## 3. 저장은 자동입니다

- **저장 버튼이 없습니다.** 직접 바꾼 값은 대부분 바꾸는 즉시 저장됩니다.
  경험치나 함께한 시간처럼 저절로 쌓이는 값은 약 1분마다 저장됩니다. 설정 창의 예외는 1장 4-2에 있습니다.
- 앱 안의 방법(1장 6절)으로 끄면 끄기 직전에 저장하도록 만들어져 있습니다.
  강제로 끝난 경우에는 마지막 약 1분 동안 바뀐 값 중 일부가 남지 않을 수 있습니다(1장 6절).
- 저장 파일의 위치를 보여주는 화면은 **앱 안에 없습니다.** 아래 3-1이 그 자리입니다.

### 3-1. 저장 파일이 있는 곳

| 운영체제 | 폴더 |
|---|---|
| macOS | `~/Library/Application Support/Vibelab/StickMate/` |
| Windows | `%USERPROFILE%\AppData\LocalLow\Vibelab\StickMate\` |

이 폴더 안에서 보게 되는 파일입니다.

| 파일 이름 | 무엇 |
|---|---|
| `stickmate_character.json` | 지금 쓰는 저장 파일. 레벨 · 장비 · 설정 · 할일이 전부 여기 들어 있습니다 |
| `stickmate_character.prev.json` | 바로 앞 세대의 사본 |
| `character_save.v8.backup.json` 처럼 숫자가 붙은 파일 | 저장 형식이 바뀌기 전에 남긴 백업 |
| `stickmate_reserved_bar_restore.json` | **Windows에서만, 그리고 작업 표시줄 자동 숨김을 쓸 때만** 생깁니다. 원래 설정 값을 적어 둔 파일입니다(1-2) |
| `FreezeForensics` 폴더 | **모든 사용자에게 생깁니다.** 앱이나 컴퓨터가 멈췄을 때 원인을 찾기 위한 기록입니다. 들어 있는 것: ① 앱이 정상적으로 꺼졌는지 적는 한 줄짜리 파일 ② 화면 구성이 바뀌거나 앱이 멈추는 등의 일이 있을 때만 생기는 기록 파일 ③ 앱이 정상적으로 꺼지지 않았을 때, 다음 실행이 남기는 이전 실행 기록의 사본(최대 3개) |

- **앱이 켜져 있는 동안에는 이 파일을 고치지 마십시오.** 앱이 그 위에 다시 씁니다.
  파일을 만질 때는 먼저 앱을 끄십시오.
- 다른 컴퓨터로 옮기려면 앱을 끈 뒤 `stickmate_character.json` **한 파일만** 새 컴퓨터의 같은 자리에 복사하십시오.
  **폴더를 통째로 옮기지 마십시오.**
  이유: `stickmate_reserved_bar_restore.json`은 그 파일을 만든 컴퓨터 전용이어서, 다른 컴퓨터에서는 그 컴퓨터의 작업 표시줄 설정을 바꿀 수 있습니다.
  이미 폴더를 통째로 옮긴 뒤 작업 표시줄이 원래와 달리 계속 숨는다면, Windows에서 직접 바꾸십시오.
  작업 표시줄의 빈 곳을 오른쪽 클릭 → **작업 표시줄 설정** → 작업 표시줄을 자동으로 숨기는 항목을 끕니다(1장 6-1과 같은 자리).
- 이 폴더를 지우면 캐릭터가 처음 상태로 돌아갑니다. **지우기 전에 `stickmate_character.json`의 복사본을 만드십시오.**
- **StickMate는 사용자의 다른 파일을 고치지 않습니다.** 바탕 화면의 아이콘도, 다른 앱의 창도
  읽기만 하고 그 위에 그림을 그릴 뿐입니다. 옮기거나 지우거나 닫지 않습니다.
  - 운영체제 설정 중 딱 하나만 예외입니다 — **Windows 작업 표시줄의 자동 숨김**입니다.
    실행하는 동안 끄고, 종료할 때 되돌리도록 만들어져 있습니다. 1-2에 적어 두었습니다.

문제를 알려 주실 때 필요한 기록은 다른 자리에 있습니다.

| 운영체제 | 기록 |
|---|---|
| macOS | `~/Library/Logs/Vibelab/StickMate/Player.log` |
| Windows | `%USERPROFILE%\AppData\LocalLow\Vibelab\StickMate\Player.log` |

- 이 기록과 `FreezeForensics` 폴더(3-1)의 파일에는 **사용자 이름이 들어간 폴더 경로가 들어 있을 수 있습니다.**
  공개 게시판에 올리지 마십시오.

macOS에서 이 폴더를 여는 가장 쉬운 방법은 Finder의 **[이동] → [폴더로 이동…]**에 위 경로를
그대로 붙여 넣는 것입니다. Windows에서는 탐색기 주소 줄에 붙여 넣으십시오.

## 4. 딱 한 번 나오는 안내

캐릭터를 오른쪽 클릭해 버튼 5개를 **처음 펼치면** 작은 안내가 나타납니다.
(캐릭터를 숨긴 동안 톱니바퀴를 눌러 처음 펼쳐도 같습니다.)

> 커서를 올리면 각 버튼 이름이 보여요

| 항목 | 값 |
|---|---|
| 나타나는 시점 | 버튼 5개를 처음 펼친 순간 |
| 머무는 시간 | 4.5초 |
| 읽을 수 있는 총 시간 | **10.5초** (아래 참고) |
| 다시 나오는가 | **나오지 않습니다** |

**이 안내는 이 컴퓨터에서 평생 한 번만 나옵니다.**
안내가 화면에 뜨는 그 순간 "봤다"가 기록됩니다. 끝까지 읽지 않아도 마찬가지입니다.
0.2초만 보고 버튼을 접어도 다시 나오지 않습니다.

기록은 캐릭터 저장 파일과 **별개의 자리**에 남습니다.
그래서 캐릭터를 처음부터 다시 시작해도 이 안내는 돌아오지 않습니다.

**★ 안내가 떠 있는 동안에는 버튼 5개가 접히지 않습니다.**
버튼은 평소 6초 동안 아무 조작이 없으면 저절로 접히는데, 그 6초는 안내가 사라진 **뒤에** 시작합니다.
그래서 읽을 시간이 **4.5초 + 6초 = 10.5초**입니다.

> 이전 빌드에서는 두 시계가 같이 흘러서, 잠깐만 머뭇거려도 안내를 읽는 도중에 버튼이 접히고
> 안내가 함께 사라졌습니다. 그리고 이 안내는 다시 나오지 않습니다.

### 4-1. 이 안내는 버튼을 처음 연 다음에 나옵니다

★ **중요합니다.** 이 안내는 **캐릭터를 스스로 오른쪽 클릭한 뒤에만** 나옵니다.
「캐릭터를 오른쪽 클릭하십시오」라고 알려 주는 안내는 화면에 없습니다.

그래서 이 설명서의 1장이 필요합니다. 버튼 5개를 여는 법은 1장 2절에 있습니다.

## 5. 눌러도 아무 일이 없는 곳

설정 창과 캐릭터 정보 창에는 **회색이라 눌리지 않는 항목**이 있습니다.
누르면 아무 일도 일어나지 않습니다. **고장이 아닙니다.**

각 항목에는 **왜 지금 못 만지는지가 그 자리에 적혀 있습니다.**
누르기 전에 읽을 수 있습니다.

### 5-1. 두 가지를 구분하십시오

회색 항목은 두 종류이고, **해야 할 일이 정반대입니다.**

| 적혀 있는 말 | 뜻 | 해야 할 일 |
|---|---|---|
| `준비 중 — …` 으로 시작하는 줄 | 이 앱에 그 기능이 **아직 없습니다** | **찾기를 멈추십시오.** 지금 할 수 있는 일이 없습니다 |
| `준비 중`으로 시작하지 **않는** 줄 | 기능은 **있습니다.** 조건만 안 맞습니다 | 적힌 조건을 맞추면 그 자리에서 켜집니다 |

두 번째의 예: 설정 창 [캐릭터] 탭에서 **말풍선 표시**를 끄면 그 아래 세 줄이 함께 회색이 됩니다.
그 세 줄에는 `말풍선 표시를 켜면 조절할 수 있어요.`가 적힙니다.
**말풍선 표시를 다시 켜면 바로 풀립니다.**

### 5-2. 설정 창의 탭 5개

설정 창에는 탭이 5개 있습니다.

| 탭 | 상태 |
|---|---|
| **일반** | 내용이 있습니다 |
| **캐릭터** | 내용이 있습니다 |
| **이벤트** | 비어 있습니다. 탭 이름 옆에 `준비 중`이 적혀 있습니다 |
| **접근성 · 성능** | 비어 있습니다. 탭 이름 옆에 `준비 중`이 적혀 있습니다 |
| **데이터** | 비어 있습니다. 탭 이름 옆에 `준비 중`이 적혀 있습니다 |

`준비 중`은 **탭을 누르기 전에** 탭 이름 옆에서 읽을 수 있습니다. 헛걸음하지 않아도 됩니다.

### 5-3. 회색 줄이 있는 자리 6곳

| 어디 | 항목 | 화면에 적히는 말 |
|---|---|---|
| 설정 [일반] | 로그인할 때 자동 실행 | `준비 중 — 이 기능은 다음 업데이트에 들어옵니다.` |
| 설정 [캐릭터] | 포인트 컬러 (눈 · 윤곽선) | `준비 중 — 포인트 컬러 팔레트는 다음 업데이트에 들어옵니다.` |
| 설정 [캐릭터] | 말투 (반말 / 존댓말) | `준비 중 — 말투 고르기는 다음 업데이트에 들어옵니다.` |
| 설정 [이벤트] | 방해 강도 프리셋 + 자동 발동 개별 토글 | `준비 중 — 여기 적힌 항목들은 다음 업데이트에 들어옵니다.` |
| 설정 [접근성 · 성능] | 윤곽선 강조 · 애니메이션 줄이기 · 저전력 렌더링 | 같은 말 |
| 설정 [데이터] | 저장 파일 위치 · 초기화 · 네트워크(전부 기본 꺼짐) | 같은 말 |

> **앱 안에서 저장 파일 위치를 볼 방법이 없습니다.** 이 줄은 회색입니다.
> 경로는 이 설명서 **3-1**에 적혀 있습니다.

### 5-4. 캐릭터 정보 창의 [상점] 탭

캐릭터 정보 창에는 탭이 4개 있습니다 — **[장비] [외형] [보관함] [상점]**.

**[상점] 탭은 비어 있습니다.** 누르면 한 줄만 나옵니다.

> 상점은 다음 업데이트에 들어옵니다.

★ **설정 창과 다른 점**: [상점]은 탭 이름 옆에 `준비 중`이 **붙지 않습니다.**
눌러 본 뒤에야 비어 있다는 것을 알 수 있습니다.

## 6. 첫날에 알아 두면 좋은 것

| 상황 | 어떻게 되는가 |
|---|---|
| 전체화면 게임을 켠다 | 캐릭터도 톱니바퀴도 창도 전부 사라집니다. 게임을 끄면 돌아옵니다 |
| 전체화면 앱(게임 아님)을 켠다 | 창 · 버튼 · 메모 카드만 사라집니다. 캐릭터는 남고, **캐릭터를 오른쪽 클릭하면 그대로 다시 열리도록** 만들어져 있습니다(3장 3절) |
| `⌃⌥⌘K`로 직접 숨긴다 | **캐릭터만** 사라집니다. 열어 둔 창 · 메모 카드는 남고, 화면 오른쪽 위에 **톱니바퀴가 나타납니다**(3장 2-2) |
| 캐릭터를 왼쪽 버튼으로 집는다 | **한마디 합니다.** 잡은 자리(머리 · 다리 · 몸통)에 따라 다릅니다(1장 8-1) |
| 캐릭터를 왼쪽 버튼으로 끈다 | 집어서 던질 수 있습니다 |
| 캐릭터를 오른쪽 버튼으로 누른다 | **버튼 5개가 펼쳐집니다.** 조작은 여기서 시작합니다(1장 2절) |
| 창 바깥을 클릭한다 | 창이 닫히지 않습니다. 그 클릭은 아래 앱으로 갑니다 |
| `ESC`를 누른다 | 창이 닫히지 않습니다 |

앱을 끄는 방법은 1장 6절에 있습니다.

## §0. 실행 전 (5분)

### 0-1 ★ 작업표시줄 원복 원장 확인 — **첫 실행 전에**
PowerShell을 열고 그대로 붙여넣기.

```powershell
$old = "$env:USERPROFILE\AppData\LocalLow\DefaultCompany\StickMate\stickmate_reserved_bar_restore.json"
if (Test-Path $old) { Get-Content $old } else { "흔적 없음 - 갚을 빚이 없다" }
```
- `흔적 없음` 또는 `"active": false` → **할 일 없음. 다음으로.**
- `"active": true` → **안 갚은 빚이다.** 아래를 실행한 뒤 진행:
```powershell
$new = "$env:USERPROFILE\AppData\LocalLow\Vibelab\StickMate"
New-Item -ItemType Directory -Force -Path $new | Out-Null
Move-Item $old "$new\stickmate_reserved_bar_restore.json"
```
> **깨지면 무슨 뜻인가**: 이 파일이 고아가 되면 사용자님 작업표시줄이 **자동 숨김이 꺼진 채 복구 수단 없이** 남는다. CLAUDE.md 원칙 3의 승인된 예외가 **사후에 무너지는 유일한 경로**다.

### 0-2 ★★ 온보딩 기회 — **지금이 이 컴퓨터에서 유일한 첫 실행이다**
회사명이 `DefaultCompany` → `Vibelab`으로 바뀌어 **레지스트리 `HKCU\Software\Vibelab\StickMate`가 비어 있다.**
macOS에서는 plist에 플래그가 남아 「첫 실행」이 **한 번도 재현되지 않았다.**

- ❌ **`docs/COMPANY_RENAME_MIGRATION.md` §2-(2) 레지스트리 복사 스크립트를 지금 돌리지 마세요.**
  돌리면 온보딩 플래그가 따라와서 **첫 실행 안내가 안 뜬다.** (이 스크립트는 오늘 안 돌려도 됩니다.)
- ★ **세이브 복사 §2-(1)은 A-1 직후에 돌리세요.** 순서가 중요합니다:
  **A-1(새 캐릭터로 온보딩 확인) → 앱 종료 → 세이브 복사 §2-(1) → 다시 실행 → A-2부터 진행.**
  이유: 새 캐릭터는 **보관함에 일반 등급밖에 없어서 A-3(등급 리본)을 잴 수 없습니다.**

### 0-3 기록 준비
바탕화면에 `StickMate확인` 폴더를 만든다. **스크린샷 파일명 = 항목 번호.** 예: `A-3.png`, `C-2.png`, 여러 장이면 `A-3-2.png`.

## §A. 기본 상태에서 (15분)
**설정: 표시 배율 100% · 작업표시줄 하단 · 자동 숨김 OFF · 모니터 1대**

- [ ] **A-1 · ★ 첫 실행 온보딩** — **한다**: 앱을 처음 실행하고 손대지 말고 20초 본다.
  **본다**: 톱니(**화면 오른쪽 가장자리**, 기본 위치는 오른쪽 끝에서 30pt) 근처에 첫 실행 안내가 뜨는가, 무엇을 하라고 말하는가.

  (★ **재시작이 필수다** — `[렌더품질]` 줄은 **프로세스당 한 번**만 찍혀서, 안 껐다 켜면 **실행 시점의 옛 배율**이 찍힌다. 이게 이 항목에서 가장 쉽게 나는 거짓 통과다.)

  (줄 안에 `<b>` 같은 글자가 섞여 보이는 것은 정상입니다.)

## §B. 자동 숨김 작업표시줄 (10분)
**설정 변경: [설정 > 개인 설정 > 작업 표시줄] → 자동 숨김 **ON**. 배율·위치는 그대로.**

- [ ] **B-1 · 강제 해제가 되는가** — **한다**: 자동 숨김을 켠 상태로 앱 실행.
  **본다**: 막대가 **나타나는가**. 로그에 `[작업표시줄] ★ … 해제했습니다`.
  **적는다**: `B-1.png` + 그 로그 줄.
  **깨지면**: `SHAppBarMessage(ABM_SETSTATE)`가 실제 셸에서 안 먹는 것 → 사용자 확정 요구사항(2026-09-02)이 미충족.

- [ ] **B-2 · ★★ `rcWork`가 실제로 좁아지는가 (가장 값진 항목)** — **한다**: B-1 상태에서 캐릭터를 **화면 맨 아래**로 내려 본다.
  **본다**: 캐릭터가 **막대 위에 서는가**, 아니면 막대에 **겹쳐/파묻히는가**. 로그 `[모니터지형]` 블록의 `OS0=전체(…)작업(…)` — **`전체`와 `작업` 사각형의 세로 크기가 다른가**.

# Tools/ContrastProbe — **캡처 픽셀에서** 대비를 잰다

    Tools/ContrastProbe/measure_chip.py <png> <x> <y> <w> <h> [라벨]

계산값이 아니라 **실제 빌드 캡처의 픽셀**에서 면/잉크 대비를 재는 도구다.
리더 지시(2026-09-02): *"수치는 실제 빌드 캡처의 픽셀에서 재라. 계산값만으로 보고하지 마라."*

## 왜 스크립트인가 — before/after를 **같은 방법으로** 재기 위해서다

한쪽만 새 방법으로 재면 비교가 성립하지 않는다. 이 스크립트를 before/after 양쪽에 그대로
쓰면 방법이 갈릴 수 없다.

## 교정이 먼저다 (실패하면 스크립트가 죽는다)

실행할 때마다 알려진 값 5건으로 **먼저** 교정한다. 하나라도 어긋나면 숫자를 내지 않고 종료한다 —
이 저장소의 거짓 초록은 전부 *"실패한 측정과 성공한 측정이 똑같이 생긴"* 형태였다.

| 검사 | 정답 |
|---|---|
| 흰 위의 검정 | 21.0000 |
| 동일색(흰 / 패널) | 1.0000 |
| `#767676` 대 흰 (WCAG 문서 예제) | 4.5422 |
| `#000000` 대 `#808080` (WCAG 문서 예제) | 5.3172 |

## 무엇을 돌려주는가

주어진 사각형 안에서 **최빈색(= 칩의 면)**, **최대·최소 휘도 화소(= 잉크 후보)**, 그리고
그 둘의 대비를 낸다. 글리프 안티에일리어싱 때문에 "글자색"은 한 값이 아니므로,
가장 밝은(또는 어두운) 화소를 잉크의 대표값으로 삼는다.

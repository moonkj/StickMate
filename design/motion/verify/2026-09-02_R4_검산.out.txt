  가설: 감속 0(즉시). 그 창의 평균속도가 10 pt/s가 되려면 t* = 18.9 ms
        -> 그 창의 실제 이동거리 = 1.16 pt   (소은 실측 '정지 후 추가이동 1.0~1.5pt')
  출발에서 '중간값(전속의 15%~85%)'이 한 표본도 안 잡힐 확률 = 30%
     -> n=1 관측으로 출발/정지 비대칭을 구분할 수 없다(정지 쪽 관측도 같은 앨리어싱으로 전부 설명된다).

  현행 1발 주기 = draw 0.42 + aim 0.3 + recover 0.34 = 1.06s
  화살 비행 0.62s > recover 0.34s  ->  착탄이 다음 Draw의
     0.28s 지점에 떨어진다 = 결과를 보는 비트가 0
  현행 접근 = 1.36유닛(=1.00H) / 1.50 = 0.907s   (로그 4/4 동일)
  현행 총 길이 = 0.91 + 0.55 + 3x1.06 + 0.62 + 0.55 = 5.81s

  제안 착탄 비트 = 0.26s (= 현행 초과분 0.28s와 같은 값)
  제안 1발 주기 = max(recover 0.34, flight 0.62 + beat 0.26) + draw + aim = 1.60s
  제안 총 길이(접근 삭제, 마지막 비트는 outro가 흡수)
     = 정지 0.18 + intro 0.55 + 접근 0 + 2x1.60 + (draw+aim 0.72) + flight 0.62 + outro 0.55 = 5.82s
  차이 = +0.01s (+0.2%)
  수평 정지: archeryHorizontalDamping=14.0 -> tau=71ms, 0.18s에 잔류 8.0% (4.94 pt/s)

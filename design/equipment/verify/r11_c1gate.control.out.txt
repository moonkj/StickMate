╔══ §1. 불투명 — 「이미 그렇다」를 기계로 못박는다 ══╗
  사용자 제약: "장비는 기존 컨셉처럼 투명해서 머리속이나 그런게 보이면 안됨"
  ★ 이건 신고가 아니라 **예방 지시**였고, 옳았다 — 인계본 91조각 중 불투명은 24개뿐이다.
  ★FAIL 출하 42아이템 전수 알파 = [0.55, 1.0]  (1.0 하나여야 한다)
     근거 경로: ItemCatalog.WornColor 마지막 줄 `result.a = ink.a`  —
     조각별 알파가 **존재하지 않는다.** 알파는 잉크 하나로 전역이다(페이드용).
     ⇒ 인계본의 채움 알파 14단계 · 그라디언트 2종 · 선 불투명도 4단계는
        **몸에 들여올 수단 자체가 없다.** 들이려면 BuildFillMesh 시그니처 +
        WornColor 계약 + Shape 구조체를 동시에 바꿔야 한다.

        ★ 권고: **채택하지 않는다.** 인계본에서 몸으로 오는 색은 **0개**다.

╔══ §3. 팩 저작 규칙 — 한 팩 안 색상각 스프레드 ≤ 60° ══╗
  사용자 확정 "출시 이후부터 계속 추가팩 만들거야" ⇒ 이건 1회성 판정이 아니라 영구 규칙이다.

  ── (a) design-art 가 이미 선언한 6팩 (PACK_THEME_SPEC 5-1~5-6) ──

    cyber     #009682/#518C84  스프레드   0.1°  주↔보조 ΔE 17.42  대역 OK  항등 OK  OK
    graffiti  #CC1BA9/#9C5A8E  스프레드   0.9°  주↔보조 ΔE 43.22  대역 OK  항등 OK  OK
    sports    #CC3F29/#9E655C  스프레드   0.1°  주↔보조 ΔE 43.91  대역 OK  항등 OK  OK
    ink       #9768CC/#8563AB  스프레드   0.1°  주↔보조 ΔE 16.12  대역 OK  항등 OK  OK
    military  #639400/#798C51  스프레드   0.5°  주↔보조 ΔE 34.79  대역 OK  항등 OK  OK
  OK   design-art 6팩이 장비 게이트(스프레드·ΔE·대역·항등)를 전부 통과한다
    ★ 이 6팩은 색상각을 **≤0.9° 안에서** 잡고 주↔보조 변별을 **채도·밝기로** 만든다.
       ⇒ 60° 는 목표가 아니라 **천장**이다. 실무 관행은 이미 훨씬 좁다.

  ── (b) 왜 60° 인가 — 「잡탕」 기준선을 실측해서 정한다 ──
    현행 출하 장비 4부위 임의 조합 1296가지의 색상각 스프레드:
      최소 2.4° · 25% 173.4° · 중앙 184.2° · 75% 188.0° · 최대 218.0° · 평균 172.3°

    문턱 후보별 통과율 — **45~60 과 75~90 이 각각 같은 값**이라 문턱이 벼랑에 안 걸린다:
      ≤  30°     36 /  1296  ( 2.8%)
      ≤  45°     52 /  1296  ( 4.0%)
      ≤  60°     52 /  1296  ( 4.0%) ← 45°와 동률(고원)
      ≤  75°     76 /  1296  ( 5.9%)
      ≤  90°     76 /  1296  ( 5.9%)
      ≤ 120°    144 /  1296  (11.1%)
  OK   문턱 60°가 고원 위에 있다 (45°와 통과 집합이 같다 ⇒ ±15° 흔들려도 판정이 안 뒤집힌다)
  OK   「잡탕」 중앙값 184.2° 가 문턱 60° 의 3배를 넘는다 (규칙이 실제로 무언가를 거른다)

  ── (c) 현행 출하 장비의 색상각 군집 (팩이 앉을 수 있는 자리) ──
        0°~   43°  폭  43.1°  11종  cape long_cape bell scarf fur poncho straw backpack cap monocle crown
       98°~  103°  폭   5.2°   3종  bandana bowtie striped
      215°~  218°  폭   3.3°  10종  goggles round pendant fairy_wings wings patch beret fedora browline sunglasses
  OK   ★ 현행 출하 24종이 이미 60° 이하 군집 3개로 갈린다 (최대 폭 43.1°) — 60° 는 새 제약이 아니라 **이미 하고 있는 것의 성문화**다

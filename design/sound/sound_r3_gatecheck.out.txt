==============================================================================
덮음   게임   숨김   등급          IsSusp  APS    현행     제안     차이
FalseFalseFalseNone        False   False  소리     소리     
FalseFalseTrue None        True    True   무음     무음     
FalseTrue FalseNone        False   False  소리     소리     
FalseTrue True None        True    True   무음     무음     
True FalseFalsePanelsOnly  False   True   소리     무음     ★
True FalseTrue PanelsOnly  True    True   무음     무음     
True True FalseFull        True    True   무음     무음     
True True True Full        True    True   무음     무음     

  전체 8행 중 갈리는 행 = 1행 (12.5%)
  ★ 갈리는 조건: 덮음=True 게임=False 사용자숨김=False → 등급 PanelsOnly
     현행 게이트로는 '소리 남'. 이것이 발표/화상회의 전체화면이다.

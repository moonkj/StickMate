# 착용 비트맵 (몸에 붙는 그림)

이 폴더에 PNG를 놓으면 `Assets/Editor/WornSpriteImport.cs`의 **AssetPostprocessor가 자동으로**
임포트 규격을 건다(메뉴를 누르는 것을 잊을 수 있는 경로를 없앴다).
설계 정본: `docs/GAME_ARCHITECTURE_REVIEW.md` §19.

## 파일 이름 규약

| 파일 | 들어가는 칸 |
|---|---|
| `<아이템에셋이름>.png` | `AccessoryDefSO.wornSpriteOverride` (앞층) |
| `<아이템에셋이름>_back.png` | `AccessoryDefSO.wornSpriteBackOverride` (몸 뒤로 가는 층) |
| `__*.png` | 규격 확인용 고정물 — 아이템과 짝짓지 않는다 |

예: `equip_head_crown.png` / `equip_head_crown_back.png`
(짝이 되는 에셋은 `Assets/_Project/Resources/Items/equip_head_crown.asset`)

## 저작 규격 (확정분)

- **캔버스**: 정사각. 저작 1024², 출하 256²(임포터가 줄인다).
- **알파**: 실루엣 밖 α=0 / 안 α=255. **중간값(반투명 그림자·글로우) 금지** —
  임의의 바탕화면 위에서 색이 섞여 사라진다. 굽기 도구가 반투명 픽셀을 세어 에러로 신고한다.
- **앞/뒤 분리**: 머리·몸통 **뒤**로 넘어가는 부분은 별도 파일(`_back`).
  안 나누면 왕관 뒷테가 머리 앞에 그려진다(실측: 인계본 12종 중 6종이 층 2개를 쓴다).
- **시점**: 한쪽 방향만 그린다 — 엔진이 좌우 반전한다. **3/4 각도 금지.**
- **조명**: 위에서 오는 광원. **좌우 비대칭 하이라이트 금지**(반전하면 어긋난다).
- **피벗**: 캔버스 정중앙(임포터가 강제한다).

## 크기와 자리

`AccessoryDefSO.wornSpriteRectInR` (머리 반경 R 배수)에 적는다.
- `x`,`y` = 앵커 기준 중심 오프셋. 앵커는 **자리가 정한다**(머리/눈/머리카락 = 머리 중심, 목/어깨 = 어깨선).
- `w`,`h` = **캔버스 전체** 크기. 잉크 크기가 아니다.
- 비워 두면 머리 지름(2R) 폭으로 되메운다 — 그게 화면에 보이면 칸이 비었다는 신호다.

`wornSpriteInkBoxInR`(알파 타이트 박스)는 **손으로 적지 않는다.**
메뉴 `StickMate/착용 비트맵/1.`이 PNG 알파에서 구워 넣는다.
이 값이 없으면 캐릭터가 투명 여백만큼 공중에 뜬다(§19-8-3).

## 롤백

칸을 **비우면** 그 아이템은 그날로 벡터로 돌아간다. 코드 변경도 세이브 변경도 없다.
벡터 데이터(`wornShapes`/코드 도형)는 아카이브로 옮기지 않고 그 자리에서 계속 컴파일·테스트된다.
